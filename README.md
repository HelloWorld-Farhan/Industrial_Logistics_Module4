# Module 4: Logistics & Fleet Control Tower

This repository houses the React/Vite codebase for **Module 4 of the Industrial Project**, focusing on real-time shipment tracking, AI route management, and inbound/outbound consolidated tracking.

## Core Features
1. **Real-Time Shipment & Truck Tracking Agent**: Live GPS tracking platform with AI deviation detection (Traffic, Border Hold, Breakdown) and automated ETA recalculation. Features a driver app connection flow via SMS and dynamic QR code tokens.
2. **Route Management AI**: Mathematical multi-modal transport evaluation across land, sea, air, and rail to optimize cost and speed parameters.
3. **Inbound/Outbound Consolidated Tracker**: A unified "Air Traffic Control" screen handling raw materials and finished products simultaneously to preemptively resolve dock congestion.

## UI/UX Standards
- High-fidelity **Dark/Light Glassmorphism** and ultra-premium micro-animations powered by **Framer Motion**.
- Fully responsive across desktop, tablet, and mobile orientations without horizontal scrolling.

## Getting Started
```bash
npm install
npm run dev
```

*Built using React, Vite, Tailwind CSS, and Framer Motion.*
